# ai العرب — مكتبة البرومبتات العربية

مكتبة عربية ثابتة للبحث والنسخ تضم **1650 برومبت في 17 مجالًا**: 300 سجل أساسي، و300 قالب إضافي، و356 موجّهًا مستوردًا، و85 موجّهًا للكتابة التخيلية وتقمّص الأدوار، و299 موجّهًا للمواقف الاجتماعية الكوميدية، و310 موجّهات جديدة للبودكاست وتجسيد الأشياء والسكتشات.

## تشغيل محلي

يتطلب متصفحًا حديثًا وPython 3:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الوظائف

- بحث عربي في العنوان والوصف ونص البرومبت.
- تصفية حسب 17 مجالًا، ومفضلة محفوظة محليًا.
- نسخ البرومبت وتنزيل النتائج الظاهرة كملف JSON.
- واجهة RTL متجاوبة، وضع داكن، تنقل بلوحة المفاتيح ودعم تقليل الحركة.
- ملف البيانات `prompts.json` مستقل عن الواجهة.

## بنية الملفات

- `index.html` — واجهة الموقع وسلوك البحث والتصفية.
- `prompts.json` — الفئات و1650 سجلًا بمعرّفات فريدة.
- `extend_catalog.py` — يضيف الدفعة الجديدة مرة واحدة، ويرفض التكرار أو التعديل الجزئي.
- `import_role_prompts.py` — يحوّل JSON من حقول `act` و`prompt` إلى بنية المكتبة، ويتجاوز البرومبتات الموجودة عند إعادة الاستيراد.
- `build_catalog.py` — مولّد الدفعة الأصلية عند توفر ملف النموذج الأولي المحلي.

لاستيراد ملف بصيغة JSON يحتوي على `act` و`prompt`: `python3 import_role_prompts.py path/to/prompts.json`. ويمكن إنشاء تصنيف جديد وإيداع كل العناصر فيه مثلًا: `python3 import_role_prompts.py path/to/prompts.json --category roleplay --category-label 'الكتابة التخيلية وتقمّص الأدوار'`. يتجاوز المستورد السجلات الموجودة عند إعادة تشغيله. لإعادة إضافة الدفعة التحريرية المعرّفة في السكربت: `python3 extend_catalog.py`.

## ملاحظات المحتوى

المدخلات الأصلية محفوظة كما كانت. البرومبتات الجديدة قوالب تحريرية قابلة للتعديل وليست نتائج مُختبرة على نموذج محدد؛ أمثلة المخرجات توضيحية. راجع الحقائق والأرقام والادعاءات، ولا تضع أسرارًا أو بيانات شخصية في أدوات عامة.

## حدود النسخة

هذا تطبيق واجهة أمامية ثابتة. المفضلة محلية في المتصفح؛ لا يوجد تسجيل دخول حقيقي أو قاعدة بيانات أو API أو بحث دلالي في هذه النسخة. زر تنزيل النتائج يصدّر العناصر المطابقة للفلاتر الحالية.
