# ai العرب — مكتبة البرومبتات العربية

مكتبة عربية ثابتة للبحث والنسخ تضم **300 برومبت في 15 مجالًا**، مبنية من النموذج الأولي المرفق ومجموعة بقية القوالب ضمن المشروع.

## تشغيل محلي

يتطلب متصفحًا حديثًا وPython 3:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الوظائف

- بحث عربي في العنوان والوصف ونص البرومبت.
- تصفية حسب 15 مجالًا، ومفضلة محفوظة محليًا.
- نسخ البرومبت وتنزيل النتائج الظاهرة كملف JSON.
- واجهة RTL متجاوبة، وضع داكن، تنقل بلوحة المفاتيح ودعم تقليل الحركة.
- ملف البيانات `prompts.json` مستقل عن الواجهة.

## بنية الملفات

- `index.html` — واجهة الموقع وسلوك البحث والتصفية.
- `prompts.json` — الفئات والـ300 سجل.
- `build_catalog.py` — يعيد بناء المكتبة بقراءة أمثلة HTML المرفق ثم التحقق من العدد والتوزيع.

لإعادة البناء: `python3 build_catalog.py`.

## ملاحظات المحتوى

المدخلات الأصلية محفوظة كأمثلة من الملف المرفق. البرومبتات الأخرى قوالب تحريرية قابلة للتعديل وليست نتائج مُختبرة على نموذج محدد؛ أمثلة المخرجات توضيحية. راجع الحقائق والأرقام والادعاءات، ولا تضع أسرارًا أو بيانات شخصية في أدوات عامة.

## حدود النسخة

هذا تطبيق واجهة أمامية ثابتة. المفضلة محلية في المتصفح؛ لا يوجد تسجيل دخول حقيقي أو قاعدة بيانات أو API أو بحث دلالي في هذه النسخة. زر تنزيل النتائج يصدّر العناصر المطابقة للفلاتر الحالية.

## النشر

يمكن استضافة الملفات الثابتة على GitHub Pages أو أي استضافة صفحات ثابتة بعد ضبط المصدر في إعدادات المستودع. أضف نطاق الموقع إلى `sitemap.xml` وبيانات المشاركة الاجتماعية قبل الإطلاق العام.
